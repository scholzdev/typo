Typo 0.1 Release Notes

The first public release of Typo, a native Typst editor for the Mac.

Overview

Typo 0.1 includes Typst 0.15.1 and typstyle 0.15.3. It runs on macOS 27 or later on a Mac with Apple silicon. The user interface is in English and German.

Typo is free for personal, noncommercial use. See the license for details.

Assistant

New Features

  • The assistant is optional and sends nothing until you agree to a provider. It runs on device with Apple Intelligence, with OpenRouter, OpenCode Zen, OpenCode Go or another OpenAI- or Anthropic-compatible provider, or as Claude Code in the project folder. API keys are stored only in the keychain.
  • It reads and searches the project, looks things up in a curated index of the Typst documentation, searches the web, compiles the document and views the preview.
  • A question is answered without changing anything. Settings › Intelligence decides what it may do on its own: change or create files, view the preview, read the project, search and read diagnostics.
  • Changes apply right away and show as “N Changes in M Files” with a revert bar, as an inline diff and as a ribbon in the gutter. One click reverts them.
  • Workflows run a prepared task by name: /check compiles and looks at every page, /submit is a checklist before you hand in, and /consistency settles on one spelling for every term. You can write your own.
  • Conversations are listed in the sidebar, with groups, an archive and multi-selection.
  • Explain with AI explains the selected text.

Bibliography

New Features

  • A BibTeX editor with all fields, More Fields and a check of the required fields.
  • Insert Citation (⇧⌘C) and completion of bibliography keys.
  • Add Reference looks up a DOI, arXiv ID or ISBN and appends the entry to a .bib file of the project.
  • File › Connect Zotero… fills a .bib file from the Zotero app or a Zotero account and keeps it in sync.

Editor

New Features

  • Syntax highlighting with themes, fonts and cursor styles.
  • Completion comes from the Typst engine: variables, functions from imports, built-ins, and only the labels and bibliography keys you can reach. Names from other files are imported for you. A label on an equation shows the rendered equation.
  • Jump to definition, find references, rename a symbol, Go Back and Go Forward, hover documentation, signature help and quick fixes.
  • Spell checking in the language from #set text(lang:), with no red underline in math.
  • Multi-cursor editing (⌘D, ⌃⌘G, ⌃⇧↑ and ⌃⇧↓) and a Vim mode with a mode capsule and key hints.
  • A minimap, sticky headings, scope guides, rainbow brackets, bracket highlighting, highlighting of matching symbols and inlay hints.
  • Colour swatches next to rgb(…) and similar. One click opens a colour picker with sliders, value fields for every channel and an optional wheel.
  • Snippets, line wrapping with indentation, overscroll, an animated caret and typewriter scrolling in focus mode.
  • Formatting with typstyle, with a line width and guide line, optionally on save.
  • Lint hints and diagnostics inline, which you can turn off. Accessibility checks hint at missing alternative text, skipped heading levels, tables without a header, and a missing title or language.
  • A word count that counts only your words, across included files, with a writing goal.
  • Drag or paste an image, and it becomes a figure.

Export and Printing

New Features

  • One export dialog for PDF, PDF/A-2b, PDF/A-3b, accessible PDF/UA-1, PNG at 72 to 600 ppi, SVG and a project ZIP. The items in File › Export open it with their format chosen.
  • Choose the pages like in the print dialog: all pages, a range, or the pages you tick in the sidebar. (#5)
  • Settings › General › Preview and PDF can save the PDF next to the document every time you save.
  • Print from File › Print… and share the PDF from the Export button in the toolbar.
  • A document that uses a font which is not installed shows a warning before you export or print, with quick fixes that suggest installed fonts.

Known Issues

  • A page range or a selection exports an untagged PDF. PDF/UA-1 always contains every page, because Typst tags only whole documents. (#7)

    Workaround: Export all pages when the PDF needs tags, for example for accessibility.

  • Many PDF/UA-1 errors from Typst carry no position, so the issue does not point to a line. (#8)

    Workaround: Turn on accessibility checks in Settings › General to see the usual causes in the editor.

Folding

New Features

  • Fold headings, brackets, figures, tables, math, raw blocks, comments and lists.
  • A fold ribbon with nested capsules, a { ··· } badge and arrow tips, as in Xcode.
  • The fold animates like a sheet of paper while the text below reflows every frame, at up to 120 Hz. Its duration is set in Settings › Editing › Display.
  • Fold and Unfold Section and Fold and Unfold All in the View menu.
  • Move sections up and down, or drag them in the outline, even into another file.

Installation and Updates

New Features

  • Typo checks for new versions once a day and shows the release notes. You choose Install Update, Remind Me Later or Skip This Version. To check right away, choose Typo › Check for Updates…

Known Issues

  • Typo is not notarized, so macOS blocks the first launch. (#9)

    Workaround: Control-click Typo in the Applications folder and choose Open, or click Open Anyway in System Settings › Privacy & Security.

  • Typo runs only on Macs with Apple silicon. (#10)

    Workaround: None.

Localization

New Features

  • The user interface is available in English and German. (#3)
  • Settings › General › Language chooses the language of Typo independently of the system. The change applies after Typo restarts.

Packages

New Features

  • A Typst Universe browser with a detail view for every package.
  • An index of @preview packages with an offline cache. A package downloaded once works offline.
  • A local packages folder for @local and your own namespaces.

Presenter Notes

New Features

  • Add a note to a slide with Format › Add Presenter Note (⌥⌘P) or from the editor’s context menu. Typo stores it in the source as #metadata("…") <note>, so it never appears in the PDF and needs no package.
  • A note on a line of its own shows as a small card in the editor that you can write in directly. A note that shares its line with other text shows as a small note you click to edit. The note mark in the gutter switches the line between the note and its code.
  • The notes strip under the preview shows the notes of the visible slide, from every file of the project. Notes from Touying and Polylux are included. It turns on by itself in a project with notes or a slide package, and with the first note you add.
  • The AI button in the notes strip drafts a note for the visible slide. You choose whether to use it.
  • View › Presenter Notes in Editor shows notes as cards, as one-line cards, or hides them and keeps only the gutter mark.
  • Present full screen. With a second display, such as an iPad with Sidecar, Play puts the slides there and the presenter view on your display, as in Keynote. X or the Swap Displays button swaps them, and closing the presenter view ends the show.
  • The presenter view follows Keynote’s presenter display: a ready-to-advance bar, the clock, a timer for the elapsed or remaining time, the current and the next slide, and your notes with their own size and Invert Colors. A layout menu turns each part on and off, and a navigator jumps to any slide.
  • Keynote’s keys: B and W for a black or white screen, a number and Return to go to a slide, + and − for the notes size, U and D to scroll them, R to reset the timer and ? for all shortcuts.

Preview

New Features

  • The preview updates as you type, or only when you save. Click anywhere in it to jump to the line that made it.
  • Zoom, Fit Width and Fit Page, two-page spreads, page thumbnails and dark pages.
  • The preview can follow the cursor, stay locked to the main file, or show the .typ file selected in the sidebar. It can also move to its own window.

Projects and Files

New Features

  • A welcome window, recent projects and a template gallery.
  • Autosave, snapshots and per-file history.
  • Encoding, line endings and whitespace cleanup for every file.
  • Open Quickly (⇧⌘O) finds files, headings and labels. Go to Line with ⌘L, bookmarks with ⌥⌘B, and find and replace across the whole project with regular expressions.

Settings

New Features

  • Settings like Xcode’s, with back and forward, opening on General.
  • General: language, restoring open projects, file extensions, navigator detail, inline issues, accessibility checks, live preview, the PDF next to the document, and export, import and reset of all settings.
  • Appearance: theme, font, styles, cursor, light and dark.
  • Shortcuts like Xcode’s: sets you can duplicate and rename, Adapt to Current Keyboard, filters for menu, text, customized and conflicting shortcuts, and a new binding with a double-click.
  • Navigation, Editing, Snippets, Packages, Source Control, Intelligence and Components.

Source Control

New Features

  • Git changes in the gutter, with blame, a log and a Changes navigator.
  • Commit, pull, push, branches and stashes, with accounts for GitHub, GitLab and Bitbucket.

Tables

New Features

  • Edit table(…) and grid(…) in a grid like Numbers, from Format › Edit Table…, the context menu or the inspector. Typst typesets every cell, with your math, references and #set rules.
  • Spreadsheet keys: arrows, Shift-arrows, Return, Tab, Escape, copy and paste, bold and italic. Paste from Numbers or Excel, and the table grows to fit.
  • Insert, delete, duplicate and drag rows and columns. Merge and split cells.
  • Alignment per column, style presets (Plain, Grid, Header Line, Booktabs, Striped) and column widths by dragging or from the column menu.
  • Caption, label and placement of the figure.
  • The Intelligence popover sorts, adds a totals row, transposes, fills empty cells, translates, fixes capitalisation, fills sample data or formats numbers, as one undo step with a summary.
  • Done writes the table back as one undoable edit and adds missing imports.

Window and Layout

New Features

  • A toolbar like Xcode’s, with navigator and assistant toggles, a scheme capsule for the main file and export format, and toggles for the preview and the inspector.
  • Navigators for files, search, outline, issues, bookmarks and changes.
  • Editor tabs with pinning, a jump bar, a split editor and focus mode.
  • An inspector for the file, the document and the figure, table, colour, label or function call under the caret.
  • A bottom area with the issues.
  • VoiceOver support for the navigators, the editor and the table grid.
