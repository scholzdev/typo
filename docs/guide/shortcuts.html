Shortcuts

These are the default shortcuts of the menu commands. Commands that are not listed have no default shortcut.

To change a shortcut, open Settings › Shortcuts. You can duplicate and rename shortcut sets, filter by All, Menu, Text, Customized or Conflicts, and record a new binding by double-clicking. “Adapt to current keyboard” adjusts the shortcuts to your keyboard layout.

The command palette (View › Command Palette…, ⇧⌘P) runs any command by name. Show Changes Navigator, ⌘6, is available only when source control is on.
