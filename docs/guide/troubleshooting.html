Troubleshooting

This page lists problems you may meet, and what to do about them.

A font is missing

Symptom: an issue says unknown font family, or Typo shows “Some Fonts Are Missing” when you export or print.

Cause: the document names a font that is not installed on this Mac. Typst uses a replacement font.

Fix: install the font, or choose another one. For the second, put the caret on the font name and choose Navigate › Show Quick Fixes (⌘.). Typo suggests up to three installed fonts. Then export again.

A package does not load

Symptom: an @preview import fails, or the template gallery says the list could not be loaded.

Cause: Typst downloads a package the first time a document imports it, and Typo loads the template list from Typst Universe. Both need a network connection.

Fix: connect to the network and compile again. After a package has been downloaded, it is available offline. Settings › Packages lists what is installed.

PDF/UA-1 export fails without a line number

Symptom: File › Export › PDF/UA-1 (Accessible)… shows an error that does not point to a line.

Cause: this is a known limitation. Typst gives no position for many PDF/UA-1 errors.

Fix: turn on accessibility checks in Settings › General (When Exporting PDF/UA, or Always). Typo then hints at the usual causes in the editor: missing alternative text, skipped heading levels, tables without a header, and a missing title or language. The /submit workflow in the assistant also checks these.

Report a bug

To report a bug or ask for a feature, open an issue with one of the forms at github.com/scholzdev/typo/issues/new/choose. Search the existing issues first. For a security problem, do not open a public issue. Use “Report a vulnerability” on the repository’s Security tab instead.
