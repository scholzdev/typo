Typo User Guide

This guide shows how to use Typo, a native macOS editor for Typst. Each page is about one task area, and every page lists the menu commands and shortcuts it mentions.

Note: This guide does not teach the Typst language. For syntax, functions and examples, read the Typst documentation at typst.app/docs.

Topics

  • Getting startedInstall Typo, open or create a project, and make a first export.
  • WritingCompletion, snippets, formatting, multiple cursors, Vim mode, spell check, tables, images, colours and folding.
  • NavigatingOpen Quickly, the navigators, project search, references, quick fixes and split editor.
  • Preview and exportThe preview, presentation mode, export formats and printing.
  • ReferencesThe BibTeX editor, Add Reference, citations and Zotero.
  • PackagesTypst Universe, local packages, updates and templates.
  • HistoryGit in the editor, snapshots and file history.
  • AssistantModel providers and agents, privacy, permissions, workflows and the MCP server.
  • ShortcutsA table of the default keyboard shortcuts.
  • TroubleshootingMissing fonts, packages, PDF/UA errors and how to report a bug.

Conventions

  • Menu paths are written like File › Save.
  • Shortcuts are the defaults. You can change them in Settings › Shortcuts.
  • Typo requires macOS 27.
